#  **Linear Regression Master Projects Collection**

###  **Overview**

This repository contains multiple real-world projects based on **Linear Regression and Regularization Algorithms** in Machine Learning.

The projects demonstrate:

* Simple Linear Regression
* Multiple Linear Regression
* Polynomial Regression
* Ridge Regression
* Lasso Regression
* ElasticNet Regression

These projects are designed for:

* Beginners learning Machine Learning
* Data Science portfolio building
* Practice for interviews
* Understanding regression algorithms deeply
* Real-world prediction systems

**# 📈 Evaluation Metrics Used**

The following regression evaluation metrics are used across projects:

| Metric   | Purpose                             |
| -------- | ----------------------------------- |
| MAE      | Mean Absolute Error                 |
| MSE      | Mean Squared Error                  |
| RMSE     | Root Mean Squared Error             |
| R² Score | Model Accuracy / Explained Variance |
